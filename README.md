# PoC 04: redacción de recomendaciones con un modelo de lenguaje local

Parte del proyecto de tesis "Plataforma web para la detección temprana del riesgo de sobreendeudamiento en mujeres emprendedoras" (UPC, Taller de Proyecto I, 2026-20).

## Estado
Pendiente.

## Objetivo único
Comprobar que un modelo de lenguaje autoalojado con Ollama redacta una recomendación por factor usando solo los fragmentos recibidos, y que cita únicamente los identificadores de esos fragmentos (validador de citas).

## Dependencias
- Modelo exacto de Ollama: decisión abierta.
- Lista cerrada del corpus de educación financiera: decisión abierta.
